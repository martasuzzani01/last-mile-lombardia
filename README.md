# Last Mile — downloadable project

Simulator of routes between real e-commerce logistics hubs and destinations in Lombardy, with the route and distance calculated on the real road network, to assess which neighboring communities fall within the impact radius.

Live site: published via GitHub Pages from this repository.

## What's real in this prototype

- **20 real, existing logistics hubs in Lombardy** (Amazon, GLS, Poste/SDA, DHL, TNT/FedEx, the Mortara Interport, the "Milano Smistamento" intermodal terminal under construction, the Adidas hub in Mantua) — each with municipality, source (press article, company press release, or official site) and, where found, its size in m². Coordinates are mostly at municipality level or based on the address cited by the source, **not surveyed cadastral geocoding** — noted case by case in the `coordNote` field of each record in `data.js`.
- **Real route and distance**, calculated live by OSRM on the OpenStreetMap road network (standard driving profile, not heavy-vehicle-specific).
- **Real air quality data**: 2024 annual NO₂ averages from six ARPA Lombardia monitoring stations, compared against the current EU limit (40 µg/m³) and the limit that takes effect in 2030 (20 µg/m³).
- **Real context data** on the growth of logistics in Lombardy: LIUC Business School mapping (warehouse floor area 10.0 → 15.8 million m² over 10 years) and Unioncamere Lombardia (the Milano Sud and Milano Est hubs, ~72,000 vehicles/day generated by the regional logistics system), plus the current case of Montichiari airport/Amazon Air.
- **Real socioeconomic indicators** per municipality, where found: average municipal income from tax returns (reprocessed Department of Finance data via comuni-italiani.it) and/or the ISTAT Social and Material Vulnerability Index (2011 census, the latest public update at municipal level). Shown individually as context, not combined into a single score.

All sources are listed at the bottom of the page and next to each data point in the tables.

## What is NOT real / is a stated estimate

- **CO₂ per trip** is the real distance × 1.0 kg CO₂/km — a factor derived from a declared average fuel consumption for 40t articulated trucks (source: Webfleet) × 2.68 kg CO₂/litre of diesel (standard conversion factor), not a measurement of the vehicle actually used.
- **The exposure index** (Low/Medium/High/Very High) is a score built specifically for this prototype, combining only the hub's size category and its proximity to the route — not the socioeconomic indicators, which are shown separately.
- Some coordinates are at municipality level (not precise address level) or, in one case (Amazon "XLI3"), the location itself is uncertain — explicitly flagged in `data.js` and in the results table.

## Known limitations

- The OSRM routing profile used (`driving`) is for cars/light vans; it does not account for heavy-vehicle transit restrictions, height, or weight limits.
- The public OSRM demo server is free to use only for low volumes, with no service guarantees (see the official policy at https://github.com/Project-OSRM/osrm-backend/wiki/API%20Usage%20Policy). For a site with real traffic, host your own OSRM instance or use a paid/API-key service.
- The ISTAT Social and Material Vulnerability Index used dates back to the 2011 census and is not updated to 2026.
- This research did not find an Italian scientific study directly linking proximity to a logistics warehouse with air quality: it is presented as an under-explored research area, not as a conclusion demonstrated by the site.
- There is no fixed ARPA monitoring station in the smaller municipalities hosting the mapped warehouses: air quality values refer to the nearest monitored provincial capitals/municipalities.

## How to switch to real heavy-vehicle (HGV) routing

The public OSRM server used by default has no truck profile. For routing that actually respects heavy-vehicle weight/height limits:

1. Sign up for free at OpenRouteService (https://openrouteservice.org/dev/#/signup) and get an API key (free plan: 2,000 requests/day).
2. In `app.js`, replace the `fetchRoute` function to call the OpenRouteService endpoint instead of OSRM:
   ```
   https://api.openrouteservice.org/v2/directions/driving-hgv?api_key=YOUR_KEY&start=LON,LAT&end=LON,LAT
   ```
   The `driving-hgv` profile also accepts vehicle weight, height, and width parameters.
3. Adapt the response parsing (the GeoJSON structure is similar but not identical to OSRM's).

## How to update air quality data with ARPA Lombardia open data

The 2024 NO₂ values in `data.js` (`AIR_STATIONS_NO2_2024`) are static. Regione Lombardia's open data portal (Socrata platform) exposes endpoints such as:

- Stations: `https://www.dati.lombardia.it/resource/ib47-atvt.json`
- Sensor data: `https://www.dati.lombardia.it/resource/nicp-bhqi.json?$where=data_inizio>'2025-01-01'`

With a `fetch()` call to these endpoints (generic Socrata documentation at dev.socrata.com) you can retrieve up-to-date data instead of the statically embedded values.
